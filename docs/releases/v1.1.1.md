Update RommPS and open it once. It updates RomM Sync and cleans up after 1.1.0 by itself.

### What changes

- The extra "RomM Sync" icon goes away. RommPS is the only app on the home screen.
- RomM Sync starts with onionHEN as well as etaHEN, so it's ready after every jailbreak.
- Autostart turns on once if you never set it. If you turn it off, it stays off.
- Old copies of RomM Sync on the console, including a pldmgr one, are updated.
- An older RomM Sync never replaces a newer one, and two never run at once.
- RommPS shows the real time of the last sync.
- RomM Sync no longer shows its own notifications while RommPS is installed. Sync results still show.
- RomM Sync updates come with RommPS now.
- Settings saved in the web UI no longer undo changes made in RommPS.
- Other websites can't change RomM Sync's settings through your browser.

### Which file do I need?

- PS5: update RommPS from ProsperoStore. Or close RommPS (Options, Close Application) and copy the PPSA76677 folder from PPSA76677.zip over the one in /data/homebrew/.
- PS5 without RommPS: send romm-sync.elf to port 9021. It no longer updates itself, so install RommPS to stay current.
- PS4 (experimental): update from Settings in the web UI, or install romm-sync-ps4.pkg.
