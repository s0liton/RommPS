Now that there is an experimental Switch 2 emulator, we can release it for the PS5 as well. I believe RommPS and RommDeck are the only clients supporting save syncs and downloading ROMs for it, but they'll catch up soon I'm sure. There are also some game library performance improvements, and general QoL enhancements.

### Added

- Handling of Wine Prefixes for ProsperoWin to make sure it can find the files we sync. Thanks to Ribelio. ([#50](https://github.com/s0liton/RommPS/issues/50))
- Nintendo Switch 2 with EglantinePS5 support downloading games and save syncing.

### Fixed

- A very large library no longer slows every sync down. Fix by antonioacg. ([#62](https://github.com/s0liton/RommPS/issues/62))
- A newer save synced down from RomM replaces save folders the emulator made for itself (PSP5 does), instead of failing with "not a usable zip". Thanks to marcussousax. ([#58](https://github.com/s0liton/RommPS/issues/58))
- No more "Couldn't set up the autostart" each time RommPS opens on a console with no etaHEN or onionHEN, and a payload manager's copy of the service is kept up to date. Thanks to antonioacg. ([#61](https://github.com/s0liton/RommPS/issues/61))
- The folder picker can open any folder on the console that we can actually read.
- A RomM server that wants a client certificate now says so, instead of "no RomM server answered".
- File names from RomM that would write outside the games or save folders are refused.
- A Switch save kept only on the device is no longer unpacked over a user's save.
- Firmware keeps its old set until the new one has fully downloaded.
- Switch updates without a title id stay in the updates folder when a preset moves folders.
- Vita title ids are read from a package inside a game folder.
