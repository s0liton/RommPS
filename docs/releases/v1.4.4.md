Nintendo Switch 2 lands on the PS5, a very large library stops slowing every sync down, and a round of fixes arrives, some from the Steam Deck side that the PS5 never got.

### Added

- Windows games under prospero-win: a save can sync from each game's own Wine prefix, with a profile you write by hand (`{game_id}` or `{game_slug}` in `bundle_dirs`). No built-in profile yet. Thanks to Ribelio. ([#50](https://github.com/s0liton/RommPS/issues/50))
- Nintendo Switch 2 with EglantinePS5: games download and saves sync, the same saves Lichii keeps on the Steam Deck. Early days for the emulator, and tested with one game.

### Fixed

- A very large library no longer slows every sync down: with 25,000 games the scan went from about ten minutes to a couple of seconds. Fix by antonioacg. ([#62](https://github.com/s0liton/RommPS/issues/62))
- A newer save from RomM replaces save folders the emulator made for itself (PSP5 does), instead of failing with "not a usable zip". Thanks to marcussousax. ([#58](https://github.com/s0liton/RommPS/issues/58))
- No more "Couldn't set up the autostart" each time RommPS opens on a console with no etaHEN or onionHEN, and a payload manager's copy of the service is kept up to date. Thanks to antonioacg. ([#61](https://github.com/s0liton/RommPS/issues/61))
- The folder picker can open any folder on the console.
- A RomM server that wants a client certificate now says so, instead of "no RomM server answered".
- File names from RomM that would write outside the games or save folders are refused.
- A Switch save kept only on the device is no longer unpacked over a user's save.
- Firmware keeps its old set until the new one has fully downloaded.
- Switch updates without a title id stay in the updates folder when a preset moves folders.
- Vita title ids are read from a package inside a game folder.
