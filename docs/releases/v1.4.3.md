I fixed a bunch of minor issues as well as some incorrect behavior when syncing certain consoles like the Switch. New UI sounds were added, and a few other enhancements.

### Added

- New interface sounds: pick Metal Gear Solid, Paper, Glass, Tones or Off in Settings.
- XPSemu Alpha 3 support: saves sync from its new hard disk folder, and Alpha 2 still works. Thanks to kostas4949. ([#46](https://github.com/s0liton/RommPS/issues/46))
- PC games (Windows, DOS and friends) now download with all their files. Thanks to Ribelio. ([#42](https://github.com/s0liton/RommPS/issues/42))

### Fixed

- Saves are compressed before uploading, so large Switch saves no longer go over RomM's upload limit. Thanks to Ribelio. ([#43](https://github.com/s0liton/RommPS/issues/43))
- Games whose RomM entry was deleted, merged or rescanned now find their new entry on their own. Thanks to Ribelio. ([#44](https://github.com/s0liton/RommPS/issues/44))
- Switch saves now sync for games without a title id in their file name. Thanks to Ribelio. ([#45](https://github.com/s0liton/RommPS/issues/45))
- Switch updates downloaded on their own go to the updates folder instead of showing up as a game.
- The library and covers no longer stay blank after an update until RommPS is reopened.
- BIOS and firmware files you already had now update when RomM's copies change.
- Emulators you don't have no longer show up as installed (PSXS5 next to SwanStationPS5, for one).
- Saves are no longer offered to move into a different emulator's folder, which could cost you a memory card.
- RommPS no longer keeps re-asking RomM for a collection it can't load; it shows the error once.
