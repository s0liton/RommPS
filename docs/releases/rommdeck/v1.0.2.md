This release is mostly focused on getting Switch 2 support and fixing some bugs and adding QoL improvements. Going forward, we now will ship an ARM build which can be used with Linux-based handhelds like t he Ayn Odin 3, Retroid Pocket, and all others. It should work on any device realistically, but report issues with specific handhelds.

### Added

- Nintendo Switch 2 with the Lichii emulator: games download into its folder and saves sync. Title ids are read from inside `.nup` files, so the file name doesn't need one.
- ARM build will now be created going forward. It should work on any Linux-ARM based device that has enough horsepower to run the app. First shown to work on an AYN Odin 3 by kiequoo. ([#59](https://github.com/s0liton/RommPS/issues/59))

### Fixed

- A very large library no longer slows every sync down: with 25,000 games the scan went from about ten minutes to a couple of seconds. Fix by antonioacg. ([#62](https://github.com/s0liton/RommPS/issues/62))
- A newer save from RomM replaces save folders the emulator made for itself, instead of failing with "not a usable zip". ([#58](https://github.com/s0liton/RommPS/issues/58))
- An emulator's games folder is no longer added a second time when SteamOS links it under two paths.
- A RomM server that wants a client certificate now says so, instead of "no RomM server answered".
- File names from RomM that would write outside the games or save folders are refused.
