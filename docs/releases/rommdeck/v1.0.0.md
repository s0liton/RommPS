The first release of RommDeck: a fully featured RomM client for the Steam Deck, based on the core codebase of RommPS, a PS5 client.

### Features
- Browse your game library and download any game to your Steam Deck.
- Sync your saves across any platform, in the background.
- Save conversion to aid in support complex save structures like Xbox, Xbox 360, Switch, Wii U, etc..
- Syncs firmware and BIOS files for you.
- Emulator profiles - Detect and auto-configures your emulators.
- Works with virtually any emulator on the Steam Deck.
- Controller first, with touch screen and mouse support.
- Runs in Game Mode and Desktop Mode.
- A beautiful and intuitive UI.

### Install

- **AppImage:** download `RommDeck-1.0.0-x86_64.AppImage`, make it executable and run it. It sets up RomM Sync, the background service, on first launch.
- **Tarball:** extract `rommdeck-1.0.0-x86_64.tar.gz` and run `./install.sh --steam` to also add it to Steam.
