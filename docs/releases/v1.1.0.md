### Added

- RommPS, a native PS5 app for RomM Sync: your RomM library on the TV, with an A to Z bar, search across every platform, game details (year, publisher, genres, play time, How Long to Beat), downloads and settings.
- Support for the standalone PS5 emulators: PSXS5 and SwanStationPS5 (PS1, one memory card per game), PS5SX2 (PS2, its shared memory cards backed up to RomM) and PS5N64 (N64).
- More than one emulator per system. Pick a main one; the others get the same games and share one save where the format matches.
- Folders you pick yourself, for systems no detected emulator plays.
- Every game's cover kept on the console, refreshed at most once a day, so the library opens fast.
- Download speeds, per download and in total. Holding Cross cancels a download and deletes what came so far.
- Versions: when RomM has several versions of a game, each one says what sets it apart (region, revision, disc).

### Changed

- Library pages load ahead of you and arrive compressed, so scrolling a big platform no longer waits on RomM.
- Files RomM scans that aren't games (a frontend's metadata.txt, artwork, readmes) are hidden and never downloaded. Neither are manuals, soundtracks or screenshots inside a game's folder.
- The PS4 build is labelled experimental: it has only been tested with RetroArch.

### Fixed

- Downloads started from the library show the game's name straight away, not "Game #id".
- Pairing with a different RomM server forgets the old server's game and save ids.

### Requirements

RomM 5.2.0 or newer (5.3.0 to back up shared memory cards), and a PS5 with etaHEN or onionHEN. RommPS needs the RomM Sync payload (romm-sync.elf) running; it shows how to load it when it isn't. See the README for setup.
