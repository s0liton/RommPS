### What's new

- RommPS, a native PS5 app. Your whole RomM library on the TV, browsable with the controller: platforms, an A to Z bar, search across everything, game details (year, genre, play time, How Long to Beat) and one-press downloads. It runs on the same Vulkan homebrew UI as mihawk-99's apps, so it's fast and looks great.
- Standalone PS5 emulators. PSXS5 and SwanStationPS5 for PS1, PS5SX2 for PS2 and PS5N64 for N64 now sync saves and states, not just RetroArch.
- More than one emulator per system. Pick a main one, and the others get the same games. Where the save format matches, they share one save.
- Your own folders. If setup doesn't recognise an emulator (or doesn't know a system), point it at the folders yourself.
- Covers are kept on the console, so the library opens fast and scrolling through hundreds of games doesn't wait on the server.
- Download speeds per game and in total, and you can cancel a download (hold Cross).
- Games with more than one version in RomM now say what sets each one apart, like the region or the disc.

### Fixed and changed

- Junk your RomM scan picked up, like a frontend's metadata.txt, no longer shows up as a game or downloads. Neither do manuals and soundtracks inside a game's folder.
- Downloads show the game's name right away instead of "Game #id".
- Pairing with a different RomM server no longer mixes up the old server's games and saves.
- The PS4 build is experimental. I've only tested it with RetroArch so far.

### Good to know

- PS5NES and Porpoise don't have presets yet, since neither works right on my console. If yours does, set it up with your own folders.
- You need RomM 5.2.0 or newer (5.3.0 to back up shared PS2 memory cards), and a PS5 with etaHEN or onionHEN plus kstuff.
- RommPS needs the RomM Sync payload running (romm-sync.elf). If it isn't, the app tells you how to load it. See the README for setup.
